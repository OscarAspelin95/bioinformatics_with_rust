# Summary
Below is a summary table of useful data structures for bioinformatic applications, a few of which have been covered in previous chapters.

| Name| Application| 
| :-- | :-- |
| Interval Tree| Allows finding intervals that overlap with a particular interval. | 
| Bloom Filter | Approximate set membership. |
| Count-min Sketch| Approximate element counts through a probalistic frequency table|
| Suffix Array| Used for efficient text search. |
| Suffix Tree| Enables fast string searches by representing suffixes in a tree. |
| Burrows Wheeler Transform | Lossless transformation, commonly used in text compression. |
| FM Index | Efficient substring search, based on the Burrows Wheeler Transform. |
| HyperLogLog| Approximating the number of distinct members in a set. |
